# Sistema de Control de Rescate y Adopción Animal

Prototipo estructural académico desarrollado exclusivamente con HTML5 semántico.

## Páginas
- `index.html`: dashboard principal.
- `reportar.html`: formulario de captura con validación HTML5 nativa.
- `rescates.html`: tabla demostrativa de casos registrados.

## Organización
- `assets/img/`: carpeta reservada para imágenes.

## Nota
Los datos mostrados son ficticios y demostrativos. El formulario no almacena datos porque este prototipo no incluye backend ni JavaScript.

## Validación
Validar individualmente los tres archivos en https://validator.w3.org/ y guardar capturas de los resultados.
